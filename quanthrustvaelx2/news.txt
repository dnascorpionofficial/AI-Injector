"WebUI Refactor 1/3"
• New Audiowide Font option added to the font picker, alongside the existing fonts ✔️

• The news panel formatting was also cleaned up into consistent styled sections instead of raw inline text ✔️
• Warning/confirmation pop-ups got a redesign — the icon now sits in a small colored badge matching the alert's color, and the pop-up itself has a sleeker notched-corner card look ✔️
• The Add/Save buttons across the applists (Performance, Alive, Cache Whitelist, Open Alive, and Sleep Settings) got a new premium pill-shaped look, with a light glowing border that matches your selected theme color, and now correctly switch fonts along with the rest of the UI ✔️
• Info panels (Logs, News, Settings, About) now properly clip their content to the rounded corners — no more square-looking edges where the scrollbar or background used to poke out past the curve ✔️
• The colorful scrollbar you're used to seeing in the Logs section now shows up consistently across News, Settings, and About too — thinner, smoother, and with a nice gradient glow ✔️
• Backup & Restore panel now flashes a random accent color each time you open it, matching the vibe of the rest of the UI ✔️
• Turned the scorpion icon animation off? It'll now actually stay off the next time you open the WebUI, before it would reset back to on fresh start ✔️
• Fixed a small hiccup where the scorpion icon could flash on screen for a split second before your saved preference kicked in ✔️
• Tapping the same log button (like Injector Log or Battery Log) repeatedly no longer causes an unnecessary jump/re-scroll - it just stays put if it's already open ✔️
• Rapid double tapping on log buttons is now guarded against, so you won't trigger a glitchy double-open anymore ✔️
• Fixed an issue where the RAM CLEANING IS OFF and BATTERY INFO IS OFF messages could sometimes fail to show up in red - they'll now always display properly ✔️
• Cleaned out several leftover/unused bits — dead CSS animation-delay rules nothing used, old counter-log input styling that wasn't hooked up to anything, empty placeholder spans, and a duplicate leftover copy of a settings-panel function ✔️
• Replaced every emoji used in confirmation pop-ups, warnings, and the "remove app" buttons across the whole WebUI with clean vector icons — no more inconsistent emoji rendering depending on your device/keyboard ✔️
• Calmed down the icon animations — the constantly shaking/spinning/flipping/bouncing icons next to toggles on Home, Apps, and other tabs are now still; the small icons inside the Settings/Info guide panels instead get a subtle heartbeat pulse ✔️
• Injector Logs tab: opening a log now properly slides it to the top and scrolls there instead of leaving it half cut off, and puts it back where it was when you close it. AI Injector Log and Battery Log boxes are also noticeably taller so you can read more before needing to scroll ✔️
• Fixed swiping in the Injector Logs section overlapping with the "Preferences Loaded" bar, and removed a glow that used to stick to the last log box you tapped ✔️
• The roaming scorpion cursor effect now works throughout the whole WebUI (previously it didn't react at all in Injector Logs / Extra tabs), no longer misfires when you're just scrolling or swiping, automatically pauses itself during Export Settings/Export Logs, and its "strike" impact is simplified (no more screen flash or vibration, fewer effects layered at once) so rapid tapping won't bog things down ✔️
• New: tapping the app title/name text lets you pause or resume the roaming scorpion effect on demand, with a confirmation pop-up ✔️
• Holiday effects (New Year, Valentine's, Earth Day, Halloween, Christmas) now use crisp custom icons for the floating particles and banner instead of emoji, so they look consistent on every device ✔️
• GPU Rendering confirmation now tells you exactly which mode was applied (OpenGL ES or Vulkan) instead of a generic "saved" message ✔️
• About, Settings Info, and News panels can now show more text before you need to scroll ✔️
